# OTD AI Review Booster Skill

## Purpose
Help businesses increase positive customer reviews.

## Workflow

1. Identify happy customers.

2. Send review request:
- Email
- SMS
- Chat

3. Personalize message:
Include:
- Customer name
- Recent interaction
- Appreciation

4. Monitor:
- Reviews received
- Ratings
- Customer feedback

5. Respond:
Create professional responses to reviews.

## Goals

Increase:
- Google reviews
- Customer trust
- Local search visibility
